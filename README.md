# BF Labs Skills

BF Labs 的 skill 目录站。视觉跟 [bflabs-ui](https://github.com/Sunnyender-org/bflabs-ui) 和 [bflabs.cn](https://bflabs.cn) 同一套。

当前可访问：https://bflabs-skills.pages.dev

正式域名：`skills.bflabs.cn`（Pages 已登记，还差一条 DNS CNAME）。

本地打开 `index.html`。Cloudflare Pages 项目 `bflabs-skills` 和官网同一个账号，生产分支是 `main`。后续静态更新：

```bash
./scripts/deploy.sh
```
